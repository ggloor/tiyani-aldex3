# CLR vs TSS with Constant

Early exploration of adding a constant to the CLR normalization before
comparing with TSS. Precursor to the coefficient.sm approach.

## Results

- contstant_clr_vs_tss_(gmma~1e-5)_plots.pdf - CLR with constant added, gamma ~ 0
- contstant(1)_clr_vs_tss_(gmma~1e-5)_plots.pdf - CLR with constant=1, gamma ~ 0

## Purpose

Tests whether adding a constant to CLR brings its results closer to TSS.
This line of investigation led to the coefficient.sm approach used in the
Summer 0.1 scripts.

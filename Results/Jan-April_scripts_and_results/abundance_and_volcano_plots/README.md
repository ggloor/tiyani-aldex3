# Abundance vs P-value and Volcano Plots

MA-style plots (abundance vs p-value) and volcano plots comparing CLR
and TSS results.

## Results

- abundance_vs_pval_clr_tss_gamma03.pdf (Mar 27) - abundance vs p-value at gamma=0.3
- abundance_vs_pval_clr_tss_gamma05.pdf (Mar 27) - abundance vs p-value at gamma=0.5
- volcano_clr_tss_gamma05.pdf - volcano plot comparing CLR and TSS at gamma=0.5

## Plot types

Abundance vs p-value (MA-style): x = mean abundance, y = -log10(padj).
Shows whether significant features tend to be high or low abundance.

Volcano: x = effect size (estimate), y = -log10(padj).
Shows the magnitude and significance of differential abundance together.

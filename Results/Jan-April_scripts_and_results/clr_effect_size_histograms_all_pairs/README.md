# CLR Effect Size Histograms - All Pairs

Visualizes the distribution of effect sizes (estimates) from CLR pairwise
analysis across all 21 comparisons using histograms and density plots.

## Script

Histograms_Code.R

## What it does

Reads the pre-computed CLR p-value CSV (pairwise_pvalues_clr.csv) and produces
three visualizations of the effect size distributions:

1. Per-comparison histograms with mean, median, and zero reference lines
2. Density overlay of all 21 comparisons on one plot (rainbow colors)
3. Combined histogram pooling all comparisons together

## Input

- pairwise_pvalues_clr.csv (from Results/ - generated by a separate looped analysis script)

## Results

- effect_size_histograms.pdf - one histogram per comparison (21 pages), with mean (green), median (orange), and zero (red) lines
- effect_size_density_overlay.pdf - all 21 density curves overlaid on one plot
- effect_size_combined.pdf - single histogram of all effect sizes pooled across all pairs

# Pairwise Effect Plots - All Pairs

Basic effect cross plots (std error vs estimate) for all 21 pairwise comparisons,
with significant features highlighted.

## Results

- pairwise_analysis_plots.pdf (Jan 15) - earliest version, ALDEx2/3 initial run
- pairwise_analysis_plots_with_tss.pdf (Mar 27) - TSS normalization version

Note: The CLR version (pairwise_analysis_plots_with_clr.pdf) is in the
clr_pairwise_effect_plots_all_pairs/ folder with its script.

## Plot type

Effect cross: x = std error, y = estimate. Significant features (padj < 0.05)
colored red, with optional overlay of significance from different gamma values.

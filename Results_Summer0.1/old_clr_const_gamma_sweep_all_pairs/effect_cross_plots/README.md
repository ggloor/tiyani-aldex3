# Effect Cross Plots

2-panel effect cross plots (CLR effect space vs TSS effect space) for CLR(const) vs TSS across constants -1 to 1 by 0.1. One PDF per constant, 21 pages per PDF (all pairs).

Produced by `effect_cross_clr_const_sweep.R`. Gamma = 0.001, nsample = 128.

## Subfolders

- `gamma_0.001/` - 21 PDFs, one per constant value

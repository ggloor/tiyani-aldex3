- `cent_vs_mage_TSS_side_gamma0.001.Rda` - TSS-side regression (red dots where TSS more sig)
- `eld_vs_kin_CLR_side_gamma0.001.Rda`
- `eld_vs_kin_TSS_side_gamma0.001.Rda`

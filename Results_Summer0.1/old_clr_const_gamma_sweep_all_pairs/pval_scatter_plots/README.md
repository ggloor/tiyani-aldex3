# P-value Scatter Plots

-log10(FDR) scatter plots of CLR(const) vs TSS across gamma and constant combinations. All 21 pairwise comparisons, one page per pair.

## Subfolders

- `gamma_0.001/` - constants -1 to 1 by 0.1 (from `clr_vs_tss_sweep_gamma_constant.R`)
- `gamma_1e-05/`, `gamma_1/`, `gamma_2/`, `gamma_3/` - constants 1-4 (from `clr_const_vs_tss_sweep.R`)
- `clr_constant_sweep/` - alternative run from `clr_const_vs_tss_sweep.R` with constants -3/-2/-1/1
